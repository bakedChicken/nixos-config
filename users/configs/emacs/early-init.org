#+DESCRIPTION: Early init Emacs configuration file

* UI configuration
** Turn off headbars

#+begin_src emacs-lisp
  (menu-bar-mode -1)
  (scroll-bar-mode -1)
  (tool-bar-mode -1)
#+end_src

** Fonts

#+begin_src emacs-lisp
  (let ((mono-spaced-font "FiraCode Nerd Font")
      (proportionately-spaced-font "Sans"))
  (set-face-attribute 'default nil :family mono-spaced-font :height 125)
  (set-face-attribute 'fixed-pitch nil :family mono-spaced-font :height 1.0)
  (set-face-attribute 'variable-pitch nil :family proportionately-spaced-font :height 1.0))
#+end_src

** Follow symlinks

Since config files are managed by Home Manager, I need this option enabled, because instead of files we have symlinks to the nix store

#+begin_src emacs-lisp
  (setq vc-follow-symlinks t)
#+end_src
