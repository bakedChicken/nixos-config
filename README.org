* What this is

One flake for every machine I run: a storage server, two Kubernetes (k3s) clusters (see [[file:kubernetes/README.org][kubernetes/README.org]]) and two development machines. Nix is used as a configuration language only: no loops, conditions or custom functions in machine definitions.

| File                              | Holds                                                                                                                                     |
|-----------------------------------+-------------------------------------------------------------------------------------------------------------------------------------------|
| ~flake.nix~                       | inputs, the shared modules, and every machine: the development machines, storage-station's hardware and OS, both clusters and their nodes |
| ~storage-station.nix~             | storage-station's services: SMB, media apps, reverse proxy, the edge server's container host, dashboard                                   |
| ~workstation/~                    | the development machines' desktop and artur's home-manager configuration                                                                  |
| ~kubernetes/~                     | what every cluster node runs, the cluster add-ons, and the platform Argo CD syncs                                                         |
| ~secrets/~, ~kubernetes/secrets/~ | agenix secrets; ~rekeyed/~ holds them encrypted per machine                                                                               |

* How a machine is built

+ ~base~: Nix, agenix, the latest kernel, NetworkManager, avahi for ~.local~ names, resolved for unicast DNS, SSH, the ~artur~ user. Addresses come only from DHCP reservations (by MAC) and SLAAC (EUI-64), so they stay the same across reinstalls.
+ ~ephemeral~: ~/~ is a tmpfs and ~/etc~ a read-only overlay; users exist only as declared. What survives a reboot is on ~/persist~:

| Machine role    | Persisted                                                                                                     |
|-----------------+---------------------------------------------------------------------------------------------------------------|
| every machine   | ~/var/lib/{nixos,systemd,NetworkManager}~, ~/var/log~, SSH host keys (the agenix identity), ~/etc/machine-id~ |
| cluster node    | ~/var/lib/{rancher,kubelet,iscsi}~; ~/etc/rancher~, ~/etc/cni~ and ~/etc/iscsi/*~ link into them              |
| workstation     | artur's ~Documents~, ~Downloads~, ~.ssh~, ~.config/mozilla~, ~.local/share/direnv~, ~.local/state/bash~       |
| storage-station | ~/var/lib/{samba,target,containers,private}~; homes, app state and the edge server's root are ZFS datasets    |

+ ~disk~: the disk layout of the VMs, an ESP and a btrfs with ~nix~ and ~persist~ subvolumes.

* Common actions

Run from a checkout on a development machine (or on storage-station, for storage-station), inside ~nix develop~.

Deploy a server or cluster node:
#+begin_src bash
deploy .#storage-station
#+end_src

Rebuild a development machine, or storage-station on the box itself:
#+begin_src bash
nixos-rebuild switch --flake .#nixos-development-environment --use-remote-sudo
#+end_src

Install a VM: boot it into the NixOS installer over the network (the router serves netboot.xyz), then keep its identity across the install:
#+begin_src bash
mkdir -p keep/persist && ssh <machine>.local 'sudo tar -C / -c etc/machine-id etc/ssh' | tar -C keep/persist -x --wildcards 'etc/machine-id' 'etc/ssh/ssh_host_*'
nix run github:nix-community/nixos-anywhere -- --flake .#<machine> --target-host root@<host> --extra-files keep --chown /persist/etc root:root
#+end_src

Flash a Raspberry Pi: build its image on an aarch64 machine, write the machine's host keys and machine ID into its root, and ~dd~ it to the SD card; it grows to the card on first boot.
#+begin_src bash
nix build .#nixosConfigurations.k8s-node-aarch64-1.config.system.build.raspberryPiImage
#+end_src

Replace a k3s server: drain it, ~kubectl delete node <machine>~, install it as above; it joins the cluster's ~init~ server as a new etcd member.

Add or change a secret, then encrypt it for the machines that use it:
#+begin_src bash
agenix edit secrets/<name>.age
agenix rekey
#+end_src

Push the platform to Argo CD:
#+begin_src bash
nix run .#push-platform
#+end_src
